# 🎬 סטודיו וידאו — התקנת הסקיל

הסקיל הופך את Claude Code (או Codex) לעורך וידאו אישי: הוא מקים לכם סטודיו עריכה מלא
(תמלול עברית, מנוע עריכה ואנימציות, אפקטים, מעברים עם סאונד) ואז עורך איתכם כל סרטון גלם
לרילס, שורטס או יוטיוב.

## מה צריך
- אפליקציית **Claude** לדסקטופ (מנוי Pro ומעלה) → לשונית **Code**, או **Codex**.
- Mac עם macOS 15 ומעלה, או Windows 10/11 (64-bit).
- כ-8GB פנויים וחיבור אינטרנט (ההתקנה מורידה כ-3GB, פעם אחת).

## התקנה בלשונית Code של Claude (הכי פשוט)
1. פותחים את אפליקציית Claude → לשונית **Code** → סשן חדש. תיקיית עבודה: כל תיקייה
   (למשל תיקיית הבית).
2. מדביקים את ההודעה הזו (ומחליפים את המיקום של הקובץ):

```
תתקין לי את הסקיל video-studio מהקובץ video-studio.zip שנמצא בתיקיית ההורדות שלי.
חלץ אותו כך שתיווצר התיקייה ~/.claude/skills/video-studio ובתוכה SKILL.md
(ב-Windows: %USERPROFILE%\.claude\skills\video-studio). אם יש שם גרסה ישנה — תחליף אותה.
תעשה אותו דבר גם ל-~/.agents/skills/video-studio (בשביל Codex).
בסוף תבדוק ש-SKILL.md קיים ותגיד לי לפתוח סשן חדש.
```

3. Claude יבקש אישור להריץ פקודות — מאשרים.
4. פותחים **סשן חדש** וכותבים: **תתקין לי סטודיו לעריכת וידאו**
   הסוכן יוביל אתכם צעד אחרי צעד (15–30 דקות, רובן הורדות) ובסוף ירנדר סרטון בדיקה קצר.

## התקנה ידנית (בלי הסוכן)
1. מחלצים את ה-ZIP → מתקבלת תיקייה בשם `video-studio`.
2. מעבירים אותה אל:
   - **Mac:** ב-Finder לוחצים ⌘⇧G, מדביקים `~/.claude/skills` ← Enter, וגוררים את התיקייה פנימה
     (אם התיקייה `skills` לא קיימת, יוצרים אותה).
   - **Windows:** בסייר הקבצים מדביקים בשורת הכתובת `%USERPROFILE%\.claude\skills` ← Enter,
     וגוררים את התיקייה פנימה.
   - **Codex:** אותו דבר, לתיקייה `~/.agents/skills` (ב-Windows: `%USERPROFILE%\.agents\skills`).
3. פותחים סשן חדש.

## אחרי שהסטודיו מותקן
פותחים סשן חדש **בתיקייה VideoStudio** (בלשונית Code בוחרים אותה כתיקיית העבודה) ואומרים
מה רוצים: "תערוך לי ריל מהסרטון הזה עם כתוביות ואפקטים".
הסרטונים המוכנים נמצאים ב-`VideoStudio/output`. את הקובץ שנגמר ב-`_share.mp4` שולחים
ומעלים; הקובץ השני הוא עותק באיכות מלאה לארכיון.

## עדכון לגרסה חדשה
מתקינים את הסקיל שוב (אותה הודעה, הגרסה הישנה מוחלפת), ואז בסשן חדש בתיקיית הסטודיו:
"תעדכן את הסטודיו". הפרויקטים, הסרטונים והמפתחות נשארים.

## שאלות נפוצות
- **כמה זה עולה?** הסקיל והכלים חינמיים. Remotion (מנוע העריכה) חינמי לאדם פרטי ולעסק של
  עד 3 אנשים; עסק של 4 ומעלה צריך רישיון Remotion. תמלול מקומי חינמי; תמלול בענן (למחשבים
  חלשים) — ל-Deepgram יש קרדיט חינם.
- **מה זה עושה למחשב?** הכול מותקן בתוך תיקייה אחת (VideoStudio) תחת המשתמש שלכם.
  רוצים להסיר? מוחקים את התיקייה.
- **מפתחות לשירותים?** רק אם בוחרים תמלול בענן או סרטוני סטוק. מדביקים אותם בקובץ
  `api-keys.txt` שבתיקיית הסטודיו (לא בצ'אט) — הסוכן יסביר איפה.
- **הסוכן מבקש אישור לכל פקודה?** בתוך תיקיית הסטודיו בלבד, קובץ `.claude/settings.json`
  מאשר מראש רק את הכלים של הסטודיו עצמו: פקודת `studio` (העריכה, הרינדור, התמלול),
  ה-ffmpeg וה-uv שבתוך התיקייה `tools`, קריאה של התיקיות `projects`, `output`, `input`
  ומדריכי הסטודיו, וקריאת התיעוד באתר של Remotion. **חסום במפורש:** מחיקה מלאה של תיקיות,
  `sudo`, וקריאה או עריכה של קובץ המפתחות `api-keys.txt`. כל פקודה אחרת עדיין מבקשת אישור.
  אפשר לפתוח את הקובץ ולקרוא אותו. ב-Codex מאשרים גישה לרשת בזמן ההתקנה ומסמנים את התיקייה
  כמהימנה.
- **מה יוצא מהמחשב?** כברירת מחדל כלום מהסרטונים שלכם: התמלול, העריכה והרינדור רצים מקומית.
  לרשת יוצאים רק: הורדות ההתקנה (הכלים ומודל התמלול), הורדת אימוג'ים, אייקונים וסרטוני סטוק
  כשמבקשים, ו**רק אם בוחרים תמלול בענן** — קובץ שמע (בלי וידאו) לשירות התמלול שבחרתם.
  הסטודיו כותב שורה לפני כל שליחה כזו.
- **משהו נתקע?** כותבים לסוכן: "תבדוק שהסטודיו תקין".

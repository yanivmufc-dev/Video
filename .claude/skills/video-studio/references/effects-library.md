# Effects library — sounds, transitions, emoji, icons, B-roll, music

Everything lives in `remotion/public/library/`. All of it is safe for commercial social media.
Contents: 1. Sounds · 2. Where sounds go · 3. Visual effects without assets · 4. Emoji ·
5. Icons & logos · 6. B-roll & photos · 7. Music · 8. Red flags · 9. Credits

## 1. Sounds (`library/sfx/`)

Use the name without extension in `plan.json` (`"sfx": "pop"`). If the same name exists in
several folders, `bundled/` wins over `mine/` over `synth/`.

**bundled/** — real recordings, all CC0 (Kenney, uisfx, Remotion's CC0 set), all leveled to the
same loudness (so a gain means the same thing for every sound):

| name | use | name | use |
|---|---|---|---|
| pop | emoji/sticker enters | bubble | chat bubbles, softer pop |
| click | caption chips, list items, UI taps | mouse-click | cursor clicks in screen demos |
| tick | counters, single key | pluck | light accent |
| ding | a number / fact lands | bell | a big reveal |
| success | done / ✓ | success-soft | gentle success |
| error | wrong / blocked | error-soft | gentle "no" |
| whip | whip transition | whoosh-quick | very short swish |
| shutter | flash / screenshot | shutter-old | retro photo |
| swipe | slide / swipe | page-turn | page or slide change |
| switch / toggle | on/off | open / close | a card opens/closes |
| notification | message pops up | question | a question appears |
| cash | money, price | sparkle | magic / idea |
| power-up | upgrade, level-up | punch | hard hit on a word |
| thud | soft drama hit | scroll | scrolling a page |
| glitch-blip | tiny digital blip | | |

**synth/** — generated by `studio sfx-make` from math (no license at all): `whoosh` (0.55 s,
the default transition whoosh), `whoosh-short`, `riser` (build-up, 0.9 s), `boom`, `typing`
(1 s), `chime`, `glitch` (0.35 s), `swipe-up`, plus synth versions of pop/click/tick/ding.

**mine/** — the member's own sounds (drop WAV/MP3 files here; only files they have the rights to).

## 2. Where sounds go

| Visual event | Sound | Gain |
|---|---|---|
| sticker / emoji pops in | pop / bubble | 0.6–0.75 |
| keyword caption page (punchy style) | click or pop | 0.35–0.45 |
| number / counter lands | ding (counter start: tick) | 0.6 |
| transition | see edit-plan.md §6 (automatic) | 0.6 |
| the problem moment (wash/glitch) | error / glitch / thud | 0.6–0.8 |
| the solution / reveal | chime / sparkle / success / bell | 0.6–0.8 |
| before a reveal | riser ending ON the reveal word (`sfxOffset: -0.9`) | 0.5 |
| typing on screen | typing | 0.5 |
| CTA | swipe / notification / pop | 0.6 |

8–18 cues per minute. Voice is never changed; the final master brings everything to −14 LUFS.

## 3. Visual effects without assets

Built into the kit (see edit-plan.md): 11 full-screen scene kinds + `chart`, `burst`
(confetti/sparkles/emoji), `waveform` (voice-reactive), caption `emojis`, `look` color grades
(natural, punchy, cinematic, warm, cool, bw, vintage, vhs, neon), `letterbox`.


All of these are generated in code (no licensing, no downloads): `flash`, `lightleak`,
`glitch`, `vignette`, `wash`, all transitions, counters, arrows, circles, lists, titles.
For more, Remotion's own effects package is installed — `@remotion/effects` has ~70 GPU effects
(`glow`, `chromaticAberration`, `whiteNoise` (grain), `speckle` (dust), `scanlines`,
`tvSignalOff`, `lut`, `halftone`, `starburst`, `zoomBlur`…) applied with the `effects={[...]}`
prop on `<Solid>`, `<Img>`, `<Video>`. Use them in custom components (animation-cookbook.md).

## 4. Emoji (`library/emoji/<codepoints>/`)

`studio fetch emoji 🔥 🤯 ✅` → Microsoft **Fluent** emoji as scalable SVG (MIT, no credit).
35 common ones come preinstalled. Styles in the `emoji` overlay:
- `fluent` (default) — glossy colorful, sharp at any size.
- `animated` — Google **Noto animated** Lottie (`studio fetch emoji 🔥 --style animated`).
  License CC BY 4.0 → the post caption needs "Emoji: Google Noto (CC BY 4.0)".
- `flat` — Noto flat SVG (Apache 2.0).
Without a fetched asset the system emoji font is used, which differs between Mac and Windows.

## 5. Icons & logos

`studio fetch icon lucide:rocket tabler:brand-whatsapp logos:youtube-icon --color "#F71C8A"`
→ `library/icons/<set>/<name>.svg` via Iconify. Approved sets: lucide (ISC), tabler, ph,
heroicons, iconoir (MIT), mdi, material-symbols, ri, carbon (Apache 2.0), logos/simple-icons
(CC0 files — but logos are trademarks: fine to identify a product, never imply endorsement).
Search names at icon-sets.iconify.design. For a company's own logo prefer its official press
kit, unchanged (no recolor, no stretch).

## 6. B-roll & photos

`studio fetch broll "typing on laptop" --n 3` searches **Pexels** (then Pixabay), downloads
vertical clips, normalizes them (30 fps, H.264, no audio) into `library/broll/` with a
`.license.json` next to each. Both licenses: free commercial use, no attribution.
Needs the member's own free key in `api-keys.txt` (`PEXELS_API_KEY`; the member signs up at
pexels.com/api and pastes the key — the account is theirs). Search in simple **English** keywords.
**Always make a contact sheet of downloaded clips and look before using them** — relevance is
everything (subject imagery beats generic stock).
The member's own clips/screenshots: put them in `projects/<name>/assets/` and reference them
as `assets/file.mp4` (ingest long clips first if they're phone footage).

## 7. Music

Default: **none**. Creators add trending/licensed audio inside Instagram/TikTok (TikTok
business accounts: Commercial Music Library; Instagram: Meta Sound Collection). If the member
wants a bed baked in: a track they have rights to, into `library/music/`, then
`"music": {"src": "library/music/x.mp3", "volume": 0.12}` (auto-ducks under speech).
Pixabay/Uppbeat "free" music can still get Content ID claims — warn before using.

## 8. Red flags — looks free, isn't

- Mixkit clips marked **Restricted** (personal use only) — same site, same URL style as the
  free ones. Many overlay/light-leak clips there are Restricted now.
- The meme sounds inside `@remotion/sfx` (Vine boom, SpongeBob, Windows XP…) — not free.
- BBC Sound Effects (non-commercial), YouTube Audio Library outside YouTube, Zapsplat/
  Videezy/Lordicon free tiers (credit required), OpenMoji (ShareAlike), Twemoji (credit),
  LottieFiles scraping (terms forbid automated downloads), "Animated Fluent Emoji" repos
  (personal use only).
- Anything CC BY-NC (non-commercial) — businesses can't use it.
- Never bundle files from Pexels/Pixabay/Mixkit into something you redistribute; download per use.

## 9. Credits

Every downloaded file has a `<file>.license.json`. Before publishing:
`studio fetch credits projects/<name>` prints the credit line if anything used requires one
(usually nothing).
